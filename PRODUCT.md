# Product
<!-- impeccable:product-schema 1 -->
## Platform
android
## Users
League organizers, club managers, players, viewers, and platform administrators using the existing role-based sports management app.
## Product Purpose
Manage fixtures, live scoring, standings, club rosters, merchandise orders, and offline synchronization for the NASCON app development module.
## Operating Context
Three-member hackathon team. Existing NestJS, PostgreSQL, Redis backend and React Native Android client. Local browser support requested for immediate review.
## Capabilities and Constraints
Preserve literal API contracts, role permissions, offline queues, scoring and roster rules. No Firebase, Supabase, BaaS, Prisma, or fixture libraries. Do not commit or push local redesign work. Local backend uses a development salt, not submission credentials.
## Brand Commitments
User selected the supplied TeamReach-style reference: soft white surfaces, rounded club cards, Barlow Condensed bold sports headings and scores with Poppins body text, masonry sports photography, pastel calendar cards, and clean SVG icons. Use red and golden yellow instead of blue. Include light/dark themes, reduced-motion-aware transitions, and responsive phone/desktop layouts. Emoji controls are explicitly rejected.
## Evidence on Hand
Existing implementation, organizer specification, repository rules, demo seed data, and user feedback rejecting the previous generic layout.
## Product Principles
Prioritize the next operational action. Distinguish live and saved data. Keep real workflows usable. Respect reduced motion and readable type.
